Purpose
A small public repository used to observe how a newly published GitHub page is discovered by web crawlers and whether it later appears in public search results.

This repository is a measurement fixture only. It does not claim to control, trigger, or guarantee crawling or search indexing by Google or any other search engine.
Unique test phrase
quartz-heron-aetherglass-7k9m

Use this exact phrase as one of the search probes when checking whether this README becomes discoverable.
Test procedure
1. Publish this repository publicly on GitHub.
2. Record the repository URL and publication time.
3. Submit the repository URL to the Gemini Notebook URL Tester, if desired.
4. Record the source-processing result separately from search-engine results.
5. Check the exact repository URL and the unique test phrase after 24 hours, 72 hours, and 7 days.
Important distinction
A successful fetch or an ACTIVE source status in Gemini Notebook confirms processing by the Gemini Notebook service. It does not confirm a Googlebot Search visit or inclusion in Google Search.
